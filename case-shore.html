Case Study

Shore Thing

Role: Product + Experience EngineerFormat: Six-section brand siteTools: React 19, Tailwind

Problem

A conventional event brochure would communicate information but miss the atmosphere. The website needed to make a beach-sport and DJ brand feel energetic, spatial, and time-based before visitors arrived.

Process

I structured the experience around the event’s real rhythm, using composition and motion to move visitors from activity into sunset and music.ARRIVAL → BEACH GAMES → GOLDEN HOUR → DJ SET
FORMAT: SIX RESPONSIVE, CINEMATIC SECTIONS

Solution + Outcome

The result is a React experience that behaves as a branded environment rather than a collection of generic event sections. Motion, visual pacing, and responsive composition carry the event identity.

What I owned

Experience direction, interface structure, visual system, responsive implementation, motion behavior, and final delivery.
