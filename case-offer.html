Case Study

WeIN Agentic Offer Pipeline

Role: AI Product EngineerTimeline: 2026—NowTools: n8n, LLMs, Python, RAG, pgvector

Problem

The offer workflow relied on repeated manual handoffs—from advisor input through intelligence, concept development, scoring, creation, and review. The challenge was not merely generating text; it was preserving business context, eliminating duplicates, grounding merchant and location facts, and keeping human review meaningful.

Process

I mapped the actual operating sequence, separated creative tasks from deterministic validation, and designed a multi-step orchestration where each stage has a defined input, output, and failure condition.ADVISOR → INTEL → CONCEPTS → SCORE → CREATE → REVIEW
GATES: GROUNDEDNESS · FUZZY DEDUP · AUTO-GEOCODING

Solution + Outcome

The result is an end-to-end offer engine that produces review-ready outputs while protecting quality through explicit checks. It compresses a fragmented process into a visible, repeatable pipeline without removing human approval.

What I owned

Product definition, workflow architecture, agent responsibilities, validation logic, orchestration, implementation direction, testing, and iteration with the people operating the system.
